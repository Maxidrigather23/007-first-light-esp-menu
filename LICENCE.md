## 🧩 About

**007 First Light overlay Menu** is a curated list of 007 First Light open-source tools:

- **Overlays** — on-screen helpers, layout notes, entity overlay, objective tracker
- **Quality-of-Life Helpers** — mission catalog, loadout manager, overlay notes
- **Research Notes** — stealth layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Mission Helpers
- Objective Tracker — follow mission markers on screen
- Entity overlay — visualize nearby points of interest
- Route Notes — record and review patrol paths
- Playback Speed — adjust observation pacing for study (0.1x to 5x)

### 🎨 Catalog & Loadout
- Gadget Catalog — browse tools, suits, and upgrades
- Custom Loadout Notes — organize mission gear
- Visibility Boost — improved marker contrast

### 🏋️ Stealth Layout
- Stealth Mode Notes — segment study on any layout
- Alarm Path Control — trace detection zones mid-run
- Cover Buffer Notes — chain complex maneuvers in the sandbox
